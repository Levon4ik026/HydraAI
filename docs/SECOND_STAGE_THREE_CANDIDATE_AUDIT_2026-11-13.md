# HydraAI — второй этап аудита трёх кандидатов

**Дата расчёта:** 2026-11-13  
**Рабочая ветка:** `hydra/research-validation`  
**Статус:** исследовательский отчёт; ни один кандидат не подтверждён для production.

## 1. Объём и воспроизводимость

Проверялись только замороженные конфигурации:

- **HYD-CAND-001:** RSI(14) ≥ 70 на закрытой медвежьей M5-свече → PUT, экспирация 5 минут.
- **HYD-CAND-008:** прокол минимума предыдущей завершённой UTC-недели с закрытием обратно выше него на бычьей M5-свече; точный inverse → PUT, 30 минут.
- **HYD-CAND-010:** закрытие M5 ниже минимума предыдущего наблюдавшегося завершённого UTC-дня при предыдущем close ≥ этого уровня; точный inverse → CALL, 60 минут.

Новые кандидаты и новые торговые правила не добавлялись.

### Зафиксированные данные

Использован существующий artifact общего feature-matrix workflow [43394192551](https://github.com/Levon4ik026/HydraAI/actions/runs/43394192551), а не новый скачанный набор:

- M1: **1,061,819** валидных строк; 2024-01-01 22:00 UTC — 2026-11-08 23:58 UTC.
- Causal M5 matrix: **209,936** завершённых баров, **2,653** непрерывных сегмента; 2024-01-01 22:00 UTC — 2026-11-08 23:50 UTC.
- SHA-256 исходного M1: `4a084d3af598342e2b55e52bb79558825797c64410b875ff8e83ec019972decd`.
- SHA-256 M5 matrix: `7b5640aab878e740e05c5f9b9c856e6b696f45d040c856984bb6800b2c5b1576`.

SHA matrix повторно проверен по скачанному artifact. Версии `candidate_profile_config_v2.json`, `universal_profile_engine.py` и `matched_control_block_bootstrap_v4.py` на текущем HEAD ветки совпадают с версиями, использованными в feature-matrix run.

### Правила расчёта

- Признаки доступны на close завершённой M5-свечи; вход — open следующей M5-свечи.
- Экспирация: close 1-й, 6-й или 12-й последующей M5-свечи соответственно.
- Сделки через разрывы непрерывности и границы сплитов исключены. Для CAND-008 и CAND-010 сохранён исходный non-overlap schedule.
- TRAIN: до 2025-09-17; VALIDATION: 2025-09-17—2026-04-13; TEST: с 2026-04-14 по конец snapshot. Для CAND-001/008 границы фиксированные; у CAND-010 они получены 60/80%-квантилями наблюдавшихся UTC-дат и совпали с теми же датами. На границах у CAND-010 исключено 13 потенциальных баров; у CAND-001/008 — 0.
- EMA/ADX/ATR/momentum признаки рассчитаны по завершённым барам в том же сегменте. ATR percentile использует только предыдущие 120 завершённых M5-баров, без сигнального бара. Уровни дня/недели относятся к предыдущему завершённому наблюдавшемуся UTC-периоду.
- Выплата **92% — сценарий**, а не подтверждённая выплата Pocket Option: WIN +0.92u, LOSS −1u, DRAW 0u; break-even decisive WR = 52.0833%.

Я повторно воспроизвёл frozen event cohorts из matrix: **9 из 9** сочетаний «кандидат × сплит» совпали с ожидаемыми counts. До non-overlap-фильтра найдено 1,146 raw events для CAND-001, 546 для CAND-008 и 1,511 для CAND-010; после исходного расписания приняты соответственно 1,146, 348 и 978 сделок.

## 3. Рыночные ситуации

Профили ниже используют заранее зафиксированные одномерные измерения: EMA20/EMA50 bias; ADX (<20, 20–30, ≥30); ATR percentile (нижняя/средняя/верхняя треть по предшествующим 120 барам); return за 6 баров / ATR. Background в profile report — все допустимые бары соответствующей ситуации, исключая raw trigger timestamps; это описательный перекрывающийся фон, не matched non-overlap control.

### CAND-001 — наиболее чёткий профиль

В конфигурации заранее был объявлен единственный двухфакторный профиль **EMA-UP × ATR-HIGH**. Он дал:

| Сплит | N (W/L/D) | WR | Net |
|---|---:|---:|---:|
| TRAIN | 498 (269/222/7) | 54.79% | +25.48u |
| VALIDATION | 123 (75/48/0) | 60.98% | +21.00u |
| TEST | 147 (87/60/0) | 59.18% | +20.04u |

Это самый последовательный профиль из трёх кандидатов: знак net положительный во всех сплитах, а sample size заметно лучше, чем у CAND-008. В целом у CAND-001 также положительны EMA-UP отдельно (55.18% / 58.29% / 56.94%) и ATR-HIGH отдельно (54.95% / 60.32% / 59.46%).

Но профиль не подтверждён: TEST ранее уже просматривался, а paired matched-control CI для этой комбинации пересекает ноль на VALIDATION и TEST (см. раздел 4).

### CAND-008 — предварительный EMA-DOWN профиль

Наиболее ровный одномерный сигнал — **EMA-DOWN**:

| Сплит | N (W/L/D) | WR кандидата | WR background | Lift |
|---|---:|---:|---:|---:|
| TRAIN | 136 (78/58/0) | 57.35% | 48.73% | +8.63 п.п. |
| VALIDATION | 23 (14/9/0) | 60.87% | 48.63% | +12.24 п.п. |
| TEST | 53 (31/22/0) | 58.49% | 51.45% | +7.04 п.п. |

Знак lift повторяется, но VALIDATION всего 23 сделки. Другие bins заметно менее стабильны: например, ATR-HIGH даёт 57.78% / 50.00% / 58.33%; ADX-MID — 53.16% / 58.33% / 70.00% при N=79/12/30. Последний TEST результат интересен, но не даёт основания выбирать ADX-MID по TEST.

**Вывод:** EMA-DOWN — рабочая гипотеза для будущей проверки аналогичных ситуаций, не подтверждённый фильтр.

| Профиль | TRAIN WR (N) | VALIDATION WR (N) | TEST WR (N) |

| EMA-DOWN | 53.72% (377) | 57.55% (140) | 56.56% (124) |

## 6. Локальная чувствительность параметров

Это exploratory-диагностика, а не подбор новых конфигураций. TEST уже раскрывался и не использовался для выбора победителя.

- **CAND-001, RSI14 threshold:** при 68 результат TRAIN/VALIDATION/TEST = +37.68 / −2.44 / −3.52u; при исходных 70 = +45.92 / +21.20 / +20.08u; при 72 = +10.48 / +16.80 / +18.20u; при 75 = −1.40 / +5.16 / +10.40u. Порог 70–72 выглядит лучше соседних вариантов, но широкой устойчивости ко всему диапазону нет.
- **CAND-008, expiry:** 25m = −2.00 / +1.00 / +13.16u; исходные 30m = +22.60 / +3.00 / +14.24u; 35m = −12.48 / +7.84 / +10.48u. TRAIN резко чувствителен к экспирации; 30m нельзя считать устойчивым плато.
- **CAND-010, expiry:** 55m = −18.68 / +16.72 / +5.36u; исходные 60m = +2.92 / +21.72 / +9.44u; 65m = +19.76 / +18.04 / +9.60u. TRAIN заметно меняется при сдвиге на 5 минут. 65m не объявляется новым кандидатом и не выбирается по уже просмотренным сплитам.

## 7. Итоговый вердикт

1. **CAND-001 — первый приоритет дальнейшей проверки.** Единственная из трёх стратегий с заранее объявленной двухфакторной ситуацией EMA-UP × ATR-HIGH, положительным net во всех сплитах и приемлемой выборкой. Однако matched-control TEST CI пересекает ноль, а прибыль TEST концентрируется в нескольких неделях. Статус: сильнейшая исследовательская гипотеза, не подтверждена.
2. **CAND-008 — оставить как маловыборочный lead.** EMA-DOWN показывает повторяющийся положительный lift, но VALIDATION N=45 для всего кандидата, matched-control CI везде пересекает ноль, а TEST net исчезает при исключении пяти лучших дней/недель. Экспирация чувствительна. Статус: предварительная гипотеза.
3. **CAND-010 — не повышать в приоритете.** TRAIN почти без преимущества (+2.92u), max DD 31.40u, 7–8 подряд убытков в TRAIN/VALIDATION, TEST paired lift близок к нулю и незначим по block CI. При 90% payout TRAIN отрицательный. EMA-DOWN и ATR-HIGH — только направления для будущей проверки, не готовая рыночная ситуация. Статус: нестабильный исследовательский lead.

## 8. Ограничения и следующий шаг

- TEST ранее уже просматривался в исследовательском цикле; это **не независимый pristine holdout**. Никакой результат выше не называется независимым подтверждением.
- Данные — исторические Dukascopy BID, а не точные исполнимые котировки Pocket Option. Спред, задержка, фактическая выплата по сделке и правила settlement платформы не воспроизведены.
- Bootstrap учитывает пятидневную кластеризацию, но не устраняет множественный поиск, все формы долгой зависимости или selection bias.
- Режимные bins — описательные. Background не является рандомизированным или matched non-overlap контролем. Для CAND-008/010 matched-control проверен общий кандидат, но не все режимные подгруппы.
- Локальная чувствительность параметров exploratory и не даёт права перенастраивать кандидатов на TEST.

**Рекомендуемый следующий этап:** заморозить исходные три правила без новых фильтров; первым наблюдать CAND-001 в заранее описанном EMA-UP × ATR-HIGH режиме, а CAND-008/010 оставить контрольными исследовательскими потоками. Следующую проверку проводить на действительно новых forward-данных с фактическими котировками/выплатой Pocket Option DEMO, фиксируя все сигналы и WAIT, не меняя параметры по ходу наблюдения. До этого ни один кандидат не переносить в production.

## 9. Что выполнено и что не выполнено

**Выполнено:** проверена идентичность frozen M5 matrix; повторно воспроизведены все 9 frozen cohorts; рассчитаны дневная/недельная концентрация, drawdown, loss streak, payout sensitivity, 5-дневный absolute-net bootstrap и локальная чувствительность RSI threshold / expiry; использованы существующие profile v2 и matched-control v4 artifacts.

**Не выполнено:** не скачивался новый независимый исторический период; не проводился новый GitHub Actions full-data workflow rerun; не получены Pocket Option quote-level данные и фактические выплаты; не выполнялась prospective DEMO-валидация. Поэтому выводы остаются исследовательскими.
